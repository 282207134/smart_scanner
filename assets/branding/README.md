# 应用图标

`app-icon-source.png` 是通过内置 imagegen 生成的图标原稿，使用深蓝底、金色扫描框与白色文档，外侧保留透明背景。

macOS 图标位于 `macos/Runner/Assets.xcassets/AppIcon.appiconset`，由原稿等比缩小为 16、32、64、128、256、512 和 1024 像素；1024 像素版本用于检查与后续导出。修改原稿后应重新生成全部尺寸。

生成日期：2026-11-10。
