## 为什么参考代码有选项却没有效果

原装安装目录包含 `BHYF_ImageProcessCore.dll`、`BHYF_BookProcessingDll.dll`、`dewarping.dll`、`izpimage.dll` 以及多个 OpenCV 库。它们说明原装软件除设备采集外还有独立处理组件，不能从文件名推断全部内部实现或跨平台授权。

提供的 SDK 中可以找到自动裁切矩形、多图拍照及智能拍照回调接口；浏览器示例和本地 KMServer 的覆盖范围并不完全一致。本机服务的部分拍照命令没有返回，旧项目备用采集路径又没有完整实现多文档检测、曲面矫正和自动扫描状态，因此仅切换选项无法获得原装效果。

新版将这些核心流程放到客户端共用层。接入 OpenCV 提供轮廓、透视变换和像素映射工具；展平还需要估计书页曲线，安装 OpenCV 本身不会自动完成这一功能。当前使用文字行与表格横线估计竖直变形；复杂书页、遮挡、图画页及边缘曲面仍是后续工作。
