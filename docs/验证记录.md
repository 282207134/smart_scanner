# 开发与验证记录（2026-10-13）

目标系统：Windows 与 macOS。实机环境：Windows、KMServer、已连接的 USB Camera。开发前已有修改保留，未清理用户扫描文件。

## 主要修复

1. WebSocket 大帧分包丢弃下一帧残留数据，以及异步接收被复用缓冲区覆盖。
2. 拍照路径长度解析不兼容、连接后预览未可靠打开、拍照未返回时不能保存。
3. PDF 导出消耗原图、列表路径失效、重复导出失败。改用本地合并，保留源图和列表。
4. 输出格式仅改扩展名、命名覆盖、切换 OCR 影响扫描格式、输入前缀被刷新重置。
5. 录像未保存录制器、画布尺寸错误、低帧率使视频播放时间缩短。
6. OCR 未绑定页面、厂商授权失败；接入系统 OCR，修复 Windows JPEG 转灰度解码错误。
7. 参数栏与预览布局、最小窗口溢出、模式参数错配；补上导入、页序、选页和原图查看。
8. macOS 原为空实现，现接入相机权限、设备枚举、采集、处理、Vision OCR/条码及目录授权。
9. 厂商服务输出预览却漏发打开回执时误报超时；匹配新画布的真实预览可确认打开，旧画布帧、明确失败及超时重试都有测试。
10. 自动裁切改为 OpenCV 文档四角检测和原始尺寸透视变换；预览标出实际边界，排除画布留白。没有可靠边界时保留原图并提示调整。
11. 增加多图裁切，一次拍摄分别保存每份文档；每份可以独立生成图片或 PDF，保留完整原图。
12. 手动裁切支持四角拖动；修复拖动较大时丢失角点目标、重启恢复手动模式没有区域的问题。书脊线同样可拖动。
13. 增加客户端自动扫描状态机：稳定后倒计时、变化取消、同画面去重、帧中断禁止拍摄，并显示半透明提示。
14. 接入文字行与表格横线的连续曲线映射，新增本地书籍单/双页展平；复杂书页和页边仍需调校。
15. 实拍发现切换采集尺寸后首帧可能失焦；增加对焦命令、等待和清晰帧选择。
16. 双页实拍发现靠中缝文字被截断；改为在原图校准书脊位置和倾斜方向，先确定左右页四角再做透视与曲线映射，保留少量共用中缝。

## 自动检查

测试覆盖协议、WebSocket 分包、图片格式、PDF 原图保留、Office 文本包、裁切像素映射、旋转、灰度/黑白、书籍分割，以及重复点击、文件名、模式切换和最小窗口布局。

静态检查无问题。扫描功能修复阶段的核心测试 48 项全部通过，覆盖真实裁切像素、多份输出、每份 PDF、曲线校正、自动状态变化、恢复手动模式首次拍摄及失焦首帧等待。自动去重增加细字一像素采样变化与拍摄后预览恢复的回归场景；书籍增加中缝偏移及倾斜两端的文字像素保留场景。

新增原生调用首次测试遇到 OpenCV DLL 缺少导出函数。查明依赖共享旧 AOT 导出清单影响 JIT 测试缓存后，刷新使用模块的导出并重新测试通过；新增 `tool/refresh_opencv_windows.ps1`，保留原生编译缓存，测试入口同样执行该步骤。

窗口测试新增角点/书脊大幅拖动、半透明倒计时和处理中停止。此次 10 个窗口场景中 9 个独立通过，模式切换场景的测试进程未正常结束，系统记录 `flutter_tester.exe` 的 `0xc0000005`。该场景此前曾通过。`tool/test_windows.ps1` 保留失败退出，不自动重试掩盖问题；**不能把本次窗口批量测试标为全部通过，也尚未定位原生崩溃原因**。

完成原生 DLL 导出更新与书脊修复后，单独重新执行原先异常退出的模式切换场景，本次通过。10 个窗口场景均有独立通过结果，但这不能证明此前偶发原生崩溃已根除，历史失败记录保留。

代码整理后，完整执行 `tool/test_windows.ps1`：静态检查无问题，50 项核心测试及 10 个独立窗口场景全部通过，脚本退出码为 0，没有重试。新增两个拍摄流程回归场景，确认书籍只采集一次原图、左右页命名与来源保留，以及裁切失败时保留原图、停止自动扫描并恢复可拍摄状态。本次完整通过不代表此前偶发原生崩溃原因已定位。

整理后的代码执行 `flutter build windows --release --no-pub` 成功，输出位于 `build_temp/windows/x64/runner/Release`。此前生成的 1.2.0 ZIP 未因本轮代码整理重新打包。

## Mac 验收顺序

1. 在 Mac 上检查、测试，构建 `flutter build macos --release`。
2. 允许摄像头访问，确认设备、分辨率、预览方向及保存尺寸。
3. 验证旋转、裁切和中英日文识别。
4. 更改保存目录，重启后确认权限恢复及导入权限。
5. 验证分割、证件合并、签章、PDF 与 Office 导出。
6. 安装 FFmpeg 验证摄像头录像；由用户授权屏幕录制后验证屏幕来源。
